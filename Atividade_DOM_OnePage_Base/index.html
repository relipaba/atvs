Área de trabalho

Esta estrutura funciona como ponto de partida para os exercícios. Leia o enunciado de cada atividade no documento fornecido pelo professor e desenvolva a solução dentro da seção correspondente.

Importante: consulte os arquivos de exemplo, mas adapte o código ao novo problema. IDs, classes, textos, quantidades e comportamentos poderão ser diferentes.

Antes de começar

  • Leia todo o enunciado do exercício.
  • Identifique quais exemplos anteriores podem ajudar.
  • Observe as relações entre HTML, CSS e JavaScript.
  • Faça uma alteração por vez e teste no navegador.
  • Use o DevTools para investigar elementos, classes e estilos.
  • Verifique o Console sempre que algo não funcionar.
  • Trabalhe criando suas próprias classes, ids e variáveis.

Revisão antes da entrega

Antes de considerar a atividade concluída, percorra toda a página e teste novamente cada componente.

  • Os IDs utilizados são únicos?
  • As classes do CSS correspondem às utilizadas no HTML?
  • Os elementos manipulados pelo JavaScript existem no HTML?
  • Os componentes podem ser usados várias vezes sem apresentar erro?
  • O Console do navegador está livre de erros em vermelho?
